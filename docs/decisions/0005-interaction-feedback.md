# ADR-0005：拖拽吸附/弹回与互动音效

- **状态**：Accepted
- **日期**：2026-11-11
- **决策者**：P1 交互修订
- **影响条款**：DESIGN §6.2、§2.1
- **相关**：`src/ui/PracticeScreen.js`、`src/ui/dragGeometry.js`、`src/ui/sound.js`

## 背景

T-SEQUENCE 支持拖拽后，有两个体验缺口：

1. 必须精确落在槽位内才生效；落在框附近没有“吸附”，容易产生挫败。
2. 落在空白处目前只是让浮层消失，没有“回到待选区”的反馈，孩子会以为块丢了。

同时，P1 需要一套克制、清晰的互动音效：不能刺耳、不能夸张，也不能引入外部音频资源。

## 决定

### D1：吸附半径 64px，取最近槽位

`findNearestSlot(slots, point, 64)` 以**槽位矩形边缘**为基准计算距离：

- 指针在槽位内距离为 0；
- 指针在框外 64px 内算“附近”，选最近的槽位；
- 超出 64px 不吸附；
- 拖到已占用槽位时替换该槽位，原单位移除。

半径取 64px，约等于一个 62px 槽位的宽度；在 390px 移动端不会跨到相邻槽位太远。

### D2：未命中弹回来源块，不删除原块

拖拽期间来源块一直留在待选区。只有命中槽位才写入 `#events`。

未命中时：

- 不修改任何槽位/事件；
- 拖拽浮层从当前位置用 **240ms** `cubic-bezier(0.22, 1, 0.36, 1)` 弹回来源块中心；
- 浮层缩小、淡出后移除；
- 来源块保持原样，不播放“掉落”成功音，而播放轻柔的返回音。

这样“弹回”是纯视觉反馈，不产生错误画像，也不会误判。

### D3：音效全部用 Web Audio 合成，无外部资源

`src/ui/sound.js` 用 `OscillatorNode + GainNode + DynamicsCompressor` 合成：

- 频率集中在中低频，短包络（40—240ms）；
- 主音量 0.55，单音音量 0.022—0.045；
- 使用 `sine` / `triangle`，不用方波、锯齿波；
- 压缩器阈值 -28dB、ratio 4，避免叠加削波；
- 正确：两个柔和上行音；错误：两个低音下行，不用刺耳蜂鸣；
- 选中/拾取/吸附/取消/返回/完成各有短提示，但都很轻。

### D4：首次手势解锁，提供 Sound / Muted 开关

- `AudioContext` 惰性创建；首次 `pointerdown` / `keydown` 时 `unlock()`；
- 不自动播放，不绕过浏览器自动播放策略；
- Header 提供 `Sound` / `Muted` 切换，`aria-pressed` 同步；
- 静音时所有播放方法直接返回，不创建上下文；
- 不把静音偏好写入学习状态或持久化存储（P1 约定）。

### D5：P1 只覆盖 T-SEQUENCE

T-FILL 仍是一次点选后自动判定；T-TYPE 不变。P8 再把吸附/拖拽/音效统一到 `PointerAdapter` 和其余题型。

## 后果

- 正面：拖拽容错更高；未命中不会“丢块”；音效轻、无资源加载、可静音。
- 负面：64px 是经验值，P8 需要按真实触控设备校准；音效是合成音，音色不如采样丰富，但更可控。
- 约束：音效必须保持低音量、短时长；任何新增音效都不得使用高频尖啸或长尾。

## 被否决的方案

| 方案 | 否决原因 |
|---|---|
| 只有精确命中槽位才生效 | 低龄触控容错差，容易挫败 |
| 未命中直接删除块/置灰 | 孩子会以为块丢了，且污染状态 |
| 用外部 mp3/wav | 增加资源、网络、版权与加载失败面 |
| 用尖锐“错误”蜂鸣 | 与 DESIGN 的温和反馈冲突 |
| 音效默认开启且无开关 | 家庭/教室场景不可控 |
