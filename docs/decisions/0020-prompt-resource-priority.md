# ADR-0020：提示词资源优先级

- **状态**：Accepted
- **日期**：2026-11-11
- **决策者**：P9 提示词修订
- **影响条款**：DESIGN §2.1
- **相关**：`promptSelector.js`、`PracticeScreen.js`

## 背景

练习页原先固定显示单词本身，所有题型都露出答案；同时内容已有句子、音标、中文翻译，
却没有统一的提示词选择规则。

P9 初版按句子→音标→中文→单词；
后续根据孩子反馈改为中文优先、IPA 同屏辅助，句子只留给 T-CLOZE。

## 决定

新增纯函数 `selectPrompt({ word, sentences, allowIpaOnly })`，采用中文优先：

```text
translation → phonetic（同屏辅助）
```

- 中文：主提示；
- 音标：中文存在时作为副提示同时展示，帮助熟悉 IPA；
- 低年级不允许“纯音标”提示；
- 句子提示只留给 T-CLOZE；
- 单词只作为最后保底。

T-TYPE 使用 `selectRecallPrompt`，同样中文主提示 + 音标副提示，不显示目标单词。

显示时不带 `Meaning`/`Sounds` 标签，只显示内容：

```text
祖父 /ˈɡɹæmpɑː/
```

## 边界

- 提示词只读，不参与判定、调度、难度计算；
- 学习端题面指令保持英文；中文翻译作为主提示时直接显示，不加标签；
- `T-CLOZE` 不重复显示句子提示，因为句子本身就是题面；
- 句子只用于 T-CLOZE，不参与普通提示优先级；
- 内容缺失时逐级回退，不报错。

## 后果

- 正面：提示资源利用完整，减少直接露词；
- 正面：规则可测试、可解释；
- 负面：中文提示通常比音标更直接，但仍不显示目标英文词；
- 负面：低年级 IPA 仅作辅助，不保证孩子会读。
