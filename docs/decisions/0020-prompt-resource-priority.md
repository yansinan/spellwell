# ADR-0020：提示词资源优先级

- **状态**：Accepted
- **日期**：2026-11-11
- **决策者**：P9 提示词修订
- **影响条款**：DESIGN §2.1
- **相关**：`promptSelector.js`、`PracticeScreen.js`

## 背景

练习页原先固定显示单词本身，所有题型都露出答案；同时内容已有句子、音标、中文翻译，
却没有统一的提示词选择规则。

用户要求提示词改为：

1. 句子；
2. 音标；
3. 中文翻译；
4. 现有单词作为保底。

## 决定

新增纯函数 `selectPrompt({ word, sentences })`，按固定顺序选择：

```text
sentence → phonetic → translation → word.text
```

- 句子：取该词第一条非空 sentence；
- 音标：`word.phonetic`；
- 中文：`word.translation`；
- 单词：`word.text` 保底。

显示时带短标签：

```text
Sentence / Sounds / Meaning / Word
```

## 边界

- 提示词只读，不参与判定、调度、难度计算；
- 学习端具体题面保持英文；中文翻译作为 `Meaning` 提示时可以出现；
- `T-CLOZE` 不重复显示句子提示，因为句子本身就是题面；
- 后台编辑的句子优先级高于音标和翻译；
- 内容缺失时逐级回退，不报错。

## 后果

- 正面：提示资源利用完整，减少直接露词；
- 正面：规则可测试、可解释；
- 负面：有句子时可能包含目标词，等于较强提示；
- 负面：目前每词只取第一条句子，不做难度/长度选择。
