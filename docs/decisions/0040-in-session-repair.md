# ADR-0040：当次练习后半段的错题强化

- **状态**：Accepted
- **日期**：2026-11-13
- **影响条款**：DESIGN §2.1
- **相关**：`PracticeScreen`、`PracticeSession`、`Scheduler.buildRepairSpec`、`RepairAlternative`

## 背景

答错后当前题会要求重试，但同一道题重试仍使用原题型。孩子可能只是记住
当前题面，而不是在另一种脚手架下重新提取拼写。

## 决定

### D1：首次答错插入同词强化

- 只对一轮中的**第一次错误**插入；
- 同一个词一轮最多插入一次；
- 插入的是同一个词，但选择**不同题型**；
- 原题仍要求重试到正确，不改变原题结果记录。

### D2：题型选择

```text
OMISSION      → 优先 T-FILL
SUBSTITUTION  → 优先 T-EDIT
其他          → 原题型的备选池
```

绝不重复原题型。

### D3：插入位置

```text
max(当前题之后, 本轮中点)
```

即尽量放到本轮后半部分；如果当前已经在后半段，则追加到末尾。

### D4：不写额外状态

- 插入的 spec 由 `Scheduler.buildRepairSpec` 生成；
- 不额外写 `wordStates`；
- 不额外写 attempts；
- 只影响当前 PracticeSession 的内存队列。

## 后果

- 正面：错词在同一次练习中换题型再提取一次；
- 正面：不会改变原始首答记录；
- 正面：强化题进入后半段，避免刚看完答案立刻重复；
- 负面：本轮总题数会增加 1—N 题（N=本轮错词数）。
