# ADR-0043：全键盘操作与焦点恢复

- **状态**：Accepted
- **日期**：2026-11-18
- **影响条款**：DESIGN §2.1
- **相关**：`src/ui/PracticeScreen.js`、`styles/practice.css`

## 背景

所有答案控件原本都是按钮，理论上可以 Tab 到达，但存在两个问题：

1. 全局 Enter 快捷键会抢走焦点按钮的原生激活，直接点 Check；
2. 每次选择后整题重绘，焦点丢失到 body。

## 决定

- 全局 Enter 只处理非交互区域；按钮/输入框等使用原生激活；
- 答案控件额外统一处理 Enter/Space，调用自身 click；
- ← → 在同一组答案控件间循环移动；
- 渲染前记录 `data-focus-key`；
- 渲染后恢复同一控件；被禁用时恢复到下一个可用控件；
- 首题进入时聚焦第一个答案控件；
- 为 T-MATCH/T-JUDGE/T-SEGMENT 补 focus-visible 焦点环。

## 约束

- 不改变题目流程、按钮、布局或题型；
- 不影响鼠标/触摸操作；
- 不新增依赖。
