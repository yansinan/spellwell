# ADR-0039：复习间隔优先，未掌握进度不显示 100%

- **状态**：Accepted
- **日期**：2026-11-12
- **影响条款**：DESIGN §1.3
- **相关**：`Scheduler`、`masteryProgress`

## 背景

实际练习中，同一组词会在多次练习里反复出现，像“没有推进”。

审查发现两个原因：

1. 队列把未到 dueDate 的旧词当作 filler 补满题量；
2. 单词在 `probe`/`reviewing` 阶段已经算出接近 1.0 的进度，单元条可能显示 100%，
   但词还没有 `mastered`，下一轮仍会出现。

## 决定

### D1：到期/新词优先，不提前 filler

```text
到期错词 → 到期复习 → 新词
```

只有完全没有到期/新词时，才使用未到期词做“额外练习” filler。

未到期词不会因为要凑满 20 题而被反复提前复习。

### D2：进度封顶

未 `mastered` 的单词：

```text
learning   最多 88%
reviewing  最多 92%
probe      最多 96%
mastered   100%
```

单元进度由单词平均，因此未全部 mastered 时不会显示 100%。

### D3：不改变记忆曲线本身

- 间隔仍是 1/3/7/14/30；
- probe 仍等待 60 天；
- 真实 attempt 仍按原规则更新状态；
- 本修正只影响队列填充和显示，不改变调度算法。

## 后果

- 正面：同一词不会在未到期时被每天重复 filler；
- 正面：单元进度不会在 probe 阶段提前满格；
- 正面：孩子能看到 92% → 96% → 100% 的真实推进；
- 负面：题量可能小于后台目标；这是“不硬凑题”的取舍。
