# ADR-0022：多教材版本与后台切换

- **状态**：Accepted
- **日期**：2026-11-12
- **决策者**：词库纠偏
- **影响条款**：DESIGN §2.3、§5.3
- **相关**：`textbooks.js`、`bootstrap.js`、`AdminApp.js`、`words.json`

## 背景

此前误把 2026 人教新起点当作目标教材；实际目标为
外研版小学《新交际英语》（北京专版）。

用户要求：

1. 保留之前的人教版词库；
2. 管理后台可指定当前教材；
3. 学习端按当前教材出题。

## 决定

### D1：词条增加 `textbook`

```json
{
  "textbook": "fltrp-2026",
  "textbookLabel": "外研版新交际（北京专版）"
}
```

教材版本：

- `pep-2026`：人教版新起点（2026），583 词；
- `fltrp-2026`：外研版新交际（北京专版），891 词。

### D2：activeTextbook 存 meta

```js
meta.activeTextbook = 'pep-2026' | 'fltrp-2026'
```

- 后台“教材版本”下拉切换；
- 学习端读取 activeTextbook，只生成该教材的单元/词；
- 词库导入/导出按当前教材范围；
- 同名单词在不同教材中 ID 独立（外研 `w.fltrp-*`）。

### D3：内容库仍是一个 words store

不新增 store，避免 P2 schema 变更。
所有教材词条共存，通过 `textbook` 过滤。

### D4：切换不丢内容

- 切换只改 meta；
- 当前会话不变；
- 下一次练习按新教材；
- 两套教材都保留，后台可来回切换。

## 后果

- 正面：保留人教版，新增外研版，切换简单；
- 正面：不改变 8 store schema；
- 负面：单 store 数据量增加，后台需要按教材过滤；
- 负面：切换教材后学习进度仍按 wordId 关联；两套教材的同名但不同 ID 词不共享状态。
