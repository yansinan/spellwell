# ADR-0027：后台单元分页优先于虚拟滚动

- **状态**：Accepted
- **日期**：2026-11-12
- **影响条款**：DESIGN §2.3
- **相关**：`AdminApp.js`

## 背景

两套教材共 144 个 unit，后台一次渲染全部折叠组仍有 72 个 summary；
虚拟滚动适合“平铺大列表”，但后台是按学期/unit 的层级结构，虚拟滚动会破坏折叠上下文。

## 决定

采用**按 unit 分页**：

- 每页 12 个 unit；
- 上一页/下一页；
- 搜索时跨全部 unit 过滤，不显示分页；
- 搜索匹配 unit 标签、单词、中文；
- 默认只展开当前选中 unit；
- 切教材回到第一页。

## 后果

- 正面：实现简单，保留折叠层级；
- 正面：72 个 unit 变成 6 页，键盘/触屏都稳定；
- 正面：搜索不受分页限制；
- 负面：跨页浏览需要翻页，但比长列表好定位。
