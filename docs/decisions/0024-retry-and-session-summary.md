# ADR-0024：答错重试到正确与结束页正确率/错词

- **状态**：Accepted
- **日期**：2026-11-12
- **影响条款**：DESIGN §2.1
- **相关**：`PracticeSession`、`PracticeScreen`、`completionSummary.js`

## 背景

原练习答错后只显示一句 `Next.`，900ms 后自动进入下一题：

- 孩子不知道错在哪里；
- 看不到正确答案；
- 无法重试；
- 结束页只显示“正确数 / 总数”，错词不突出。

## 决定

### D1：答错不进入下一题

- 保留当前题；
- 显示醒目提示，不使用刺眼红色；
- 显示正确答案，例如：

```text
Not quite.
The word is book.
[Try again]
```

- 重试按钮重新渲染同一题；
- 孩子也可以直接修改当前输入再 Check；
- 只有答对后才允许进入下一题。

### D2：只记录第一次作答

- `PracticeSession.submit(events, {record})`；
- 第一次提交记录到 session results 和 Scheduler；
- 重试用 `retry()` 放行，但不追加 results；
- 这样：
  - 学习状态保留首次错误；
  - 正确率口径是“第一次答对率”；
  - 不会因为重试把错词统计冲掉。

### D3：结束页顺序

1. 大号正确率（first-try）；
2. 鼓励语；
3. 错词列表；
4. Again / New practice。

正确率文案：

```text
85%
17 / 20 correct first try
```

鼓励语按正确率变化，但不出现积分/排行榜。

### D4：错词回到下一次练习

错词仍由首次错误进入 Scheduler 的错误画像/到期队列；
结束页提示它们会在下一次练习回来。

## 后果

- 正面：错误可见、答案可见、可重试；
- 正面：结束页突出正确率和错词；
- 正面：错词状态不会被重试覆盖；
- 负面：一个题可能停留较久；
- 负面：正确率是 first-try，重试后正确不会提高本次正确率。
