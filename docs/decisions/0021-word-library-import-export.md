# ADR-0021：词库单独导入/导出

- **状态**：Accepted
- **日期**：2026-11-12
- **决策者**：P9 后台内容维护
- **影响条款**：DESIGN §2.3
- **相关**：`WordLibrary.js`、`AdminApp.js`

## 背景

全量迁移 `/migration/index.html` 包含 8 个 store，不适合日常词库备份、换机或批量校对。
用户要求词库可以单独导入/导出，并且重复词自动处理。

## 决定

### D1：只导出 words

文件格式：

```json
{
  "schema": "spellwell.words.v1",
  "version": 1,
  "exportedAt": "2026-11-12T...",
  "items": [ ...word... ]
}
```

- 只含 `words`；
- 不含 `wordStates` / `graphemeStates` / `attempts`；
- 不含句子/混淆项/组合库；
- 全量迁移仍使用 `/migration/index.html`。

### D2：重复词处理

导入时按 `text` 判断重复，三选一：

| 模式 | 行为 |
|---|---|
| 合并 | 保留已有 ID/切分/reviewStatus；补空中文/音标；显式单元标题可更新单元 |
| 替换 | 覆盖切分/中文/音标/单元，reviewStatus 置 unreviewed |
| 不动 | 跳过已有词 |

新词使用导入文件中的 `id`（无冲突时），否则生成稳定新 ID。

### D3：导入落库

- 解析并校验文件；
- 应用到内容草稿；
- 跑 ContentValidator V1—V9；
- 校验通过后写入共享 IndexedDB；
- 校验失败回滚草稿，不写库；
- 导入完成后广播内容更新。

### D4：与全量迁移的边界

- 词库导入/导出：只维护内容词条；
- 全量迁移：换主机/备份，包含学习状态；
- 后台不写学习状态。

## 后果

- 正面：词库可以单独备份、交换、批量校对；
- 正面：重复词可预测地合并/替换/跳过；
- 负面：导入不包含学习状态，换机后仍需全量迁移恢复进度；
- 负面：词库文件中的 ID 若冲突会改用新 ID，引用它的句子需重新检查（当前句子库只读）。
