# ADR-0029：默认自动选择记忆周期内的单元

- **状态**：Accepted
- **日期**：2026-11-12
- **影响条款**：DESIGN §2.1
- **相关**：`unitProgress.js`、`bootstrap.js`、`main.js`、`PracticeSetupScreen.js`

## 背景

原练习设计页要求孩子每次手动选择单元，且默认只选当前单元；
已经学过但仍在记忆曲线的单元没有自动进入练习。

## 决定

### D1：单元状态

- `practiced > 0`：学过；
- `completed`：所有词都至少练过一次；
- `mastered`：所有词状态为 `mastered` 且 `errorProfile` 已清空。

### D2：默认自动选择

```text
所有 practiced > 0 且 !mastered 的单元
```

即：已经学过，但仍处于记忆周期内的单元。

- 完全 mastered 的单元默认不加入；
- 未开始的新单元默认不加入，除非满足 D3。

### D3：新单元自动加入条件

- 复习单元全部 `completed`；
- 这些复习单元总词数 `< questionsPerPractice`；
- 存在下一个未开始单元。

此时补 **一个** 下一个新单元，不连续塞入多个。

如果没有任何复习单元：

- 已有学习历史 → 自动带入下一个新单元；
- 首次使用 → 自动带入第一个新单元。

### D4：默认直接进入

- 自动选择非空 → 直接开始练习，不显示设计页；
- 自动选择为空（全部 mastered）→ 打开设计页，允许手动复习；
- 练习页提供 `Units` 按钮，随时回到设计页强制选新单元。

### D5：手动选择

设计页默认选中自动选择结果；
可以取消/加入单元，强制加入新单元。

## 后果

- 正面：每天打开直接练，减少操作；
- 正面：复习单元不会因忘记选择而漏掉；
- 正面：已掌握单元不占用题量；
- 负面：首次使用直接进入第一个单元，可能看不到选择页（可点 Units）。
