- 只收单单词；排除短语、缩写、带空格/撇号/连字符的词条；
- 同名跨单元只保留首次出现；
- 中文取第一义项；
- 有音标的保留 IPA；1—2 年级来源缺少音标；
- 切分由后台最长匹配生成；
- 所有词标记 `reviewStatus: unreviewed`。

## 5. 已知问题

1. 1—2 年级来源没有音标，提示词会落到中文或单词；
2. 3—6 年级来源与北京专版逐册对应关系需复核；
3. 三年级下词量 146，明显高于其他学期，单元内题量不均；
4. 4 个小单元不足 5 词，单 unit 练习达不到 20 题；
5. 跨单元重复按首次出现去重，部分单元词量被压缩；
6. 自动切分未人工审核。

## 6. 优化建议

1. 1—2 年级补 IPA；
2. 复核 3—6 年级单元标题和教材版本；
3. unit 模型升级为多对多 `unitRefs`，保留跨单元重复；
4. 后台增加教材版本 + 册次 + 单元标题元数据；
5. 对 4 个过小单元允许跨 unit 组题；
6. 全部词审核后再作为生产内容发布。
